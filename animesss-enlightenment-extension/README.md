# Animesss Card Helper 2.7.17

Расширение Chrome автоматически показывает статистику карточек Animesss,
проверяет задание «Познать просветление», поддерживает авто-лут и может массово
отмечать доступные карты для обмена. По желанию оно также следит за событием с
камнями духа в чате и нажимает появившийся кристалл.

## Установка

1. Откройте в Chrome страницу `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку `animesss-enlightenment-extension`.
5. Если была установлена предыдущая версия, нажмите кнопку обновления на
   карточке расширения.
6. Откройте или перезагрузите страницу на `animesss.com` либо `animesss.tv`.

После обновления расширения открытые вкладки Animesss нужно перезагрузить один
раз. Если старая вкладка успеет выполнить таймер до перезагрузки, расширение
распознает потерю контекста и остановит этот таймер без ошибки в журнале Chrome.

## Статистика карточек

Статистика загружается автоматически под существующими и вновь появившимися
карточками, включая витрину `/accshop/`. После обновления витрины новые товары
обрабатываются автоматически. Запускать «Просветление» для этого не нужно.

Если «Возвышение» уже показывает статистику конкретной карты, расширение не
дублирует её и не запрашивает спрос этой карты повторно. Это работает в магазине
АСС и на странице входящего обмена. Там, где встроенных данных нет (либо они
скрыты или ещё не заполнены), остаётся статистика расширения. Проверка повторяется
при изменениях страницы; при отсутствии «Возвышения» прежняя загрузка сохраняется.

Показатели размещены в одной компактной строке: значок и число, полное название
и точное значение — в подсказке. Крупные числа сокращаются. «Хотят» — это спрос:
сколько пользователей хотят получить карту. Это не количество лайков;
отдельного глобального счётчика лайков этот источник сайта не предоставляет.

«Дубли» — количество экземпляров этой карты у вошедшего пользователя, включая
первый экземпляр, как у «Возвышения». При отсутствии готового счётчика расширение
читает итог отфильтрованной собственной коллекции одним запросом через общую
очередь с задержками, без обхода страниц. Если счётчик прочитать не удалось,
остаётся прочерк (не выдуманный ноль). Кэш разделён по сайту и имени пользователя;
после получения/обмена карт актуальные значения можно запросить «Обновить спрос».

Статистика кэшируется на 24 часа. «Обновить спрос» обходит кэш для видимых
карточек, а «Очистить кэш» удаляет только данные Card Helper.

Основные числа показываются после первого ответа, до загрузки личных дублей.
Неиспользуемые списки желающих и обменщиков не запрашиваются: для трёх новых
карт обычно достаточно шести запросов вместо двенадцати (без учёта повторов
при сетевых ошибках). Ограничение частоты запросов сохраняется.

Сетевые запросы статистики выполняются строго по одному. Скорость можно менять
между 1, 3 и 5 запросами в секунду; по умолчанию выбрано 3. Данные из кэша
показываются сразу. Если сайт отвечает кодом `429`, расширение учитывает
указанную сервером задержку `Retry-After` перед повтором независимо от режима.

## Панель управления

Нажмите круглую кнопку `☰` справа, чтобы раскрыть панель:

- «Запустить просветление» начинает прежний обход коллекции и проверку задания.
  Повторное нажатие останавливает дальнейшие запросы. Состояние сохраняется и
  после перезагрузки обработка возобновляется, пока пользователь не остановит её
  или задание не будет завершено.
- «Обновить спрос» принудительно обновляет статистику видимых карточек.
- «Спрос карт» включает и выключает загрузку и отображение статистики. По
  умолчанию функция включена, а выбранное состояние сохраняется после
  перезагрузки. При выключении активный запрос может завершиться, но следующие
  карты из очереди уже не запрашиваются.
- «Скорость» переключает режимы по кругу: 1 → 3 → 5 запросов в секунду. Выбор
  сохраняется и применяется к следующему запросу без перезагрузки страницы.
  Фактическое время появления карточки также зависит от скорости ответа сайта:
  для полной статистики одной карты может понадобиться до трёх запросов.
- «Авто-лут» изначально выключен. После явного включения состояние сохраняется,
  расширение следит за уведомлениями о найденных картах, автоматически нажимает
  каждое из них и закрывает информационное окно. Запрос и время выдачи карты
  остаются под управлением самого сайта, поэтому после обработки уведомления
  встроенный таймер AnimeSSS может выдать следующую карту.
- «Авто-кристалл» изначально выключен. После включения расширение выполняет
  проверку сразу, а затем каждые 3 минуты по фоновому сигналу Chrome, включая
  неактивные вкладки. После «Я вернулся» сборщик ждёт загрузки новых сообщений.
  Вкладка должна оставаться открытой и не выгруженной Chrome из памяти;
  при закрытом браузере или спящем компьютере сбор не выполняется.
  Сначала оно нажимает видимую кнопку
  «Я ВЕРНУЛСЯ», если сайт показал окно отсутствия. Затем нажимает кристалл только
  в том же сообщении, где точно написано: «Шпион демонической секты отобрал 300
  мешков с камнями духа, помогите их собрать». Каждый `data-code` обрабатывается
  не более одного раза, в том числе после перезагрузки страницы. Выключение
  функции останавливает периодическую проверку.
- «Авто-взнос клуба» изначально выключен. Функция предназначена для страницы
  `https://animesss.com/clubs/boost/?id=402`: вкладку нужно оставить открытой.
  В 21:01 МСК расширение сначала перезагружает страницу клуба и после загрузки
  начинает эмулировать клавишу `S` до 22:30 МСК. Отметка в sessionStorage вкладки
  предотвращает повторную автоматическую перезагрузку в ту же московскую дату.
  При первом включении в интервале 21:01–22:30 страница также обновляется один раз.
  Перезагрузка и продолжение записываются в журнал. Chrome и компьютер должны
  оставаться запущенными: сон или приостановка вкладки могут задержать таймер.
  Начиная с 2.7.22 попытки выполняются каждые 0,5 секунды независимо от смены карты.
  Сначала нажимается видимая кнопка вклада, иначе обновления; если обеих нет — S.
  Занятая/заблокированная кнопка пропускается до следующей проверки.
  Ожидание выполняется фоновым процессом расширения через сообщения, а не таймером
  скрытой страницы. Вкладка должна оставаться открытой и не выгруженной; точный
  интервал при сне компьютера или приостановке браузера не гарантируется.
  Ограничения количества взносов и двухминутных пауз нет.
  Смена `data-card-id` позволяет продолжить цикл, но сама по себе не подтверждает
  личный успешный взнос: карту мог обновить другой участник. В 22:30
  цикл прекращается до следующего дня. Если открыть страницу между 21:01 и
  22:30, запуск начинается сразу. После 22:30 новый запуск планируется на 21:01
  следующего дня. Чтобы исключить дублирующие клики, оставляйте открытой только
  одну вкладку этой страницы. Если общий прогресс сайта достигает максимума,
  например `600/600`, клуб считается закрытым: текущий цикл прекращается и новые
  попытки взноса прекращаются. Завершённая московская дата сохраняется: до следующего
  дня не нажимается даже «Обновить», в том числе после перезагрузки страницы.
  Следующая ежедневная перезагрузка остаётся назначенной на 21:01 МСК.
- «Журнал авто-взноса» показывает последние 500 событий с временем МСК: загрузку
  скрипта на странице клуба, включение/выключение, запланированное время, начало
  цикла, попытки и выбранное действие (вклад/обновление/S/кнопка занята), ID карты,
  счётчик прогресса, смены карты, ошибки и причины
  остановки. При загрузке и пропуске запуска также пишутся исходные значения
  счётчика, наличие и блокировка кнопок. Журнал сохраняется после перезагрузки; старые события до установки
  этой версии восстановить нельзя. В окне есть обновление и очистка, текст можно
  выделить и скопировать. Для записи событий оставляйте одну вкладку клуба.
- «Массовый обмен» собирает только видимые незаблокированные карты. Перед первым
  запросом Chrome показывает подтверждение с количеством карт. Во время работы
  эта же кнопка останавливает запуск следующих запросов.
- «Очистить кэш» удаляет сохранённую статистику, не затрагивая данные сайта.

Для авто-лута, авто-взноса клуба, массового обмена и проверки задания необходимо
заранее войти в свой аккаунт Animesss в этой же вкладке.

При кратковременной сетевой ошибке запрос статистики повторяется до трёх раз.
Ошибка одной категории не останавливает отображение остальных показателей.

## Конфиденциальность

Расширение выполняет запросы только к текущему сайту Animesss, используя уже
открытую пользовательскую сессию. Оно не подключает аналитику и не отправляет
данные на сторонние домены.

В Chrome Storage сохраняются последние 500 событий авто-взноса (время и ID карт),
настройки включения, статистика карточек со сроком
жизни 24 часа, соответствия ID экземпляров
и последние 100 уже обработанных кодов кристаллов. Пароль, cookie и содержимое
сообщений расширение не сохраняет;
при включённом авто-кристалле оно локально сравнивает текст сообщений чата только
с указанной выше фразой события.

## Ручная проверка

1. На странице коллекции статистика появляется без запуска «Просветления».
2. Динамически загруженная карточка получает ровно один блок статистики.
3. Выключение «Спроса карт» скрывает статистику и останавливает очередь после
   текущего запроса; повторное включение загружает видимые карточки.
4. Кнопка скорости переключает 1, 3 и 5 запросов в секунду, а выбранный режим
   сохраняется после перезагрузки.
5. После перезагрузки настройки спроса и авто-лута сохраняют состояние.
6. После включения авто-кристалл нажимает «Я ВЕРНУЛСЯ», если кнопка видима,
   проверяет подходящий кристалл сразу и затем повторяет проверку каждые 3 минуты.
7. Отмена подтверждения массового обмена не создаёт запросов.
8. Подтверждённый обмен пропускает заблокированные карты, а кнопка остановки не
   запускает следующий запрос после завершения текущего.
9. Запуск, остановка и автопродолжение «Просветления» работают как раньше.
10. На странице клуба `id=402` авто-взнос работает только с 21:01 до 22:30 МСК,
    выполняет попытку каждые 0,5 секунды и останавливается при завершении окна
    или общем прогрессе `600/600`, без повторных обновлений в завершённый день.

## Локальная карта лабиринта (2.6.0)

В 2.7.21 на `/boss_invansion/` добавлена кнопка «Авто-S: выкл · 50 мс».
Включается вручную и повторяет события клавиши S (keydown/keypress/keyup) каждые
50 мс. При переключении вкладки, потере фокуса окна или выключении расширения
останавливается. При фокусе в поле ввода нажатия приостанавливаются. Автозапуска
после перезагрузки нет. Частоту игровых действий определяет обработчик сайта.

В 2.7.20 загрузчик проверяет связь с расширением перед запросом. Если расширение
перезагружено или выключено, карта предлагает перезагрузить страницу вместо
`Cannot read properties of undefined (reading 'sendMessage')`. Сохранённые
комнаты остаются доступны.

В 2.7.19 оба режима используют актуальный бинарный `/map/fast?v=3` без
предварительного `/map/version`. Полная загрузка поддерживает до 200 000 комнат;
для более крупной карты используйте ±100. Ошибки показывают этап, HTTP-статус
и известный код причины без токенов или полного ответа сервера. При `need_auth`
или `invalid_auth` выполняется одна повторная привязка того же устройства.
При `blocked`, отзыве устройства, конфликте, лимите устройств или проверок
автоматической смены токена/повторной регистрации нет. Кэш не удаляется.

С версии 2.7.18 загруженные общие комнаты сохраняются в IndexedDB браузера
отдельно для каждого профиля и домена. После перезагрузки кэш показывается без
обращения к серверу. Новые области дополняют старые; успешные страницы сохраняются
даже при последующем обрыве загрузки. Лимит — 200 000 последних записанных комнат.
Кнопка «Обновить данные с сервера» повторяет последний режим загрузки: выбранную
область ±100 либо всю карту (по умолчанию — всю). После перезагрузки используется
режим последнего успешного сохранения. Дата последнего пополнения кэша
не гарантирует актуальность каждой комнаты. При `blocked` кэш не удаляется.
Очистка данных сайта в браузере удаляет этот кэш; настройки и личные заметки
расширения хранятся отдельно. При ошибке записи показывается предупреждение.

На странице `/labyrinth/` появилась кнопка «🧭 Карта лабиринта» слева внизу.
Рядом расположен переключатель «Лабиринт: вкл/выкл» (с версии 2.6.2).
Выключение закрывает карту, останавливает чтение данных игры и наблюдение за
размером карты. Настройка сохраняется после перезагрузки и применяется в других
открытых вкладках лабиринта. Сохранённые комнаты и заметки не удаляются.
Для повторного включения нажмите «Лабиринт: выкл».
Карта читает реальные координаты из данных игры раз в 1,5 секунды — без сетевых запросов.
Доступны перетаскивание, масштаб колесом и кнопками, «Моя позиция», «Вся карта»,
выбор комнаты и заметки (до 160 символов). Стрелки перемещают обзор, не персонажа.
Золотая рамка обозначает текущую позицию, звезда — комнату с заметкой.

История до 20 000 комнат сохраняется в хранилище расширения отдельно для профиля.
Сначала видны только комнаты, которые сайт передал открытой странице; остальные
накапливаются при исследовании. Старые сведения могут устареть при изменении лабиринта.
Неизвестные комнаты не предсказываются. Общую карту можно загрузить отдельно.
Если профиль не определён, карта работает только до перезагрузки, с предупреждением.

Формат `labyrinthData.mapData` и названия событий взяты за ориентир из
**Animesss Labyrinth Map 10.45**, автор **VladLIO**, лицензия в исходнике **MIT**.
Сбор истории аккаунта, автоматизация шахты и игровые действия исходного скрипта не подключаются.

### Общая карта (2.7.0)

В окне карты нажмите «Загрузить общую карту». Расширение регистрирует на
`https://labyrinthmap.uk/api/device/bind` ваш ник и новый случайный идентификатор
устройства, сохраняемый в хранилище расширения. Сервер также видит IP.
Cookies Animesss, описания операций, даты и ваши маршруты не передаются.
В версии 2.7.1 при HTTP 403 регистрации допускается подтверждение ACC:
из одной страницы `/acchistory/` извлекаются только `acc_delta` (изменение ACC)
и `acc_after` (остаток после операции), максимум 100 записей. Эти числа передаются
в `acc_rows` серверу карты один раз за попытку загрузки, только по его запросу.
Сама HTML-страница, её cookies и другие поля не отправляются; числа не сохраняются
в хранилище расширения. При повторном отказе загрузка прекращается.
Доступ к новому домену требуется разрешить при обновлении расширения.

Общие комнаты загружаются постранично по `/map/full` только по нажатию кнопки;
фоновой синхронизации и отправки пройденных комнат нет. Между запросами страниц
пауза не менее 750 мс, ожидание ответа — до 15 секунд. Выключение лабиринта
прерывает загрузку после текущего запроса. Ошибки сервера показаны под кнопками;
локальная карта продолжает работать. Общая карта хранится в памяти вкладки до
перезагрузки; заметки сохраняются локально. Локально наблюдённые комнаты имеют
приоритет над общей картой. Для больших карт на дальнем обзоре комнаты группируются.

После обновления расширения перезагрузите страницу лабиринта.

## Автоматические тесты

### Мобильная закладка: заблокировать все карты A

Добавлена третья кнопка «Разблокировать только сделанное закладкой».
Новая версия хранит ID экземпляров отдельно от текстового лога:
`animesss.mobileLock.owned.v1:НИК` в localStorage текущего домена.
Перед POST блокировки ID получает статус pending, после проверки — confirmed.
Разблокировка проверяет собственную коллекцию и выбирает только A с закрытым
замком и статусом confirmed. Перед POST статус меняется на releasing; после
проверенного открытого замка запись удаляется. Pending/releasing не разрешают
автоматического повтора или разблокировки. При недоступном хранилище операция
останавливается до изменения карт. Старые версии не сохраняли ID: их блокировки
не импортируются, ручные и неизвестные замки не выбираются.

Ограничение: ручное снятие и повторная установка замка между запусками не видны
журналу. Не меняйте вручную замки учтённых карт до отмены через закладку.
Удаление данных сайта/смена браузера или домена лишает доступа к этому журналу.
Он не синхронизируется и не восстанавливается по старому текстовому логу.

Отдельный инструмент (в расширение автоматически не подключается):
`mobile-lock-install.html` — инструкция и поле копирования;
`mobile-lock-bookmark.txt` — полный адрес закладки;
`mobile-lock.js` — исходник. Сборка: `node build-mobile-lock.cjs`.

В Chrome телефона замените адрес проверочной закладки на весь текст из TXT,
откройте **свою** коллекцию `/user/cards/?name=ВАШ_НИК`, запустите закладку из
подсказки адресной строки и выберите один из двух режимов. Скрипт самостоятельно
читает коллекцию с фильтром A начиная с первой страницы, исключает A+, уже
заблокированные карты и карты в обмене/колоде. Использует штатный массовый запрос
`/ajax/page_lock_cards/` с ID незаблокированных карт данной страницы. Не использует
переключатель `lock_card` и никогда не вызывает разблокировку.

Между операциями пауза 1,5 секунды; после каждого POST страница читается повторно.
В режиме «Вся коллекция — по страницам» успехом считается подтверждённый закрытый замок.
В режиме «Незаблокированные — первая страница» запрос содержит `locked=0`,
номер страницы всегда 1. После успешного ответа массовой блокировки счётчик
увеличивается на число отправленных ID, исчезнувших из вновь прочитанной выборки.
Цикл заканчивается только при подтверждённой пустой коллекции текущего пользователя
с заголовком «0 шт.». Ошибка, отсутствие прогресса или недоступные карты на первой
странице останавливают обход без перехода вперёд. При неполном результате,
сетевой ошибке или неизвестном состоянии — остановка без повторного POST.
«Стоп» запрещает новые операции после завершения текущей проверки.
Не меняйте коллекцию параллельно, держите вкладку открытой и экран включённым.
Число страниц не зафиксировано на 76; защитный предел — 1000.

Лог содержит время, страницу, число новых/прежних блокировок, итог и ошибки.
Последние 1000 строк сохраняются в localStorage сайта, отдельно для аккаунта и
домена; «Скопировать лог» позволяет сохранить отчёт. Пароль и токен в лог не пишутся.
После перезагрузки автоматического продолжения нет. Повторный запуск начинает
с первой страницы и пропускает закрытые замки. Реальные карты при разработке
не блокировались; проверена изолированная Chromium-модель сайта, не iOS.

Дополнительный браузерный тест запускается при доступном `playwright` в NODE_PATH;
`CHROME_PATH` задаёт путь к Chrome. Без Playwright он явно пропускается.
