# Animesss Card Helper 2.4.3

Расширение Chrome автоматически показывает статистику карточек Animesss,
проверяет задание «Познать просветление», поддерживает авто-лут и может массово
отмечать доступные карты для обмена. По желанию оно также следит за событием с
камнями духа в чате и нажимает появившийся кристалл.

## Установка

1. Откройте в Chrome страницу `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку `animesss-enlightenment-extension`.
5. Если была установлена предыдущая версия, нажмите кнопку обновления на
   карточке расширения.
6. Откройте или перезагрузите страницу на `animesss.com` либо `animesss.tv`.

После обновления расширения открытые вкладки Animesss нужно перезагрузить один
раз. Если старая вкладка успеет выполнить таймер до перезагрузки, расширение
распознает потерю контекста и остановит этот таймер без ошибки в журнале Chrome.

## Статистика карточек

Статистика загружается автоматически под существующими и вновь появившимися
карточками, включая витрину `/accshop/`. После обновления витрины новые товары
обрабатываются автоматически. Запускать «Просветление» для этого не нужно.

Показываются четыре компактные всегда видимые плитки: «Владельцы», «Хотят»,
«Обмен» и «Дубли». «Хотят» — это спрос:
сколько пользователей хотят получить карту. Это не количество лайков;
отдельного глобального счётчика лайков этот источник сайта не предоставляет.

Статистика кэшируется на 24 часа. «Обновить спрос» обходит кэш для видимых
карточек, а «Очистить кэш» удаляет только данные Card Helper.

Сетевые запросы статистики выполняются строго по одному. Скорость можно менять
между 1, 3 и 5 запросами в секунду; по умолчанию выбрано 3. Данные из кэша
показываются сразу. Если сайт отвечает кодом `429`, расширение учитывает
указанную сервером задержку `Retry-After` перед повтором независимо от режима.

## Панель управления

Нажмите круглую кнопку `☰` справа, чтобы раскрыть панель:

- «Запустить просветление» начинает прежний обход коллекции и проверку задания.
  Повторное нажатие останавливает дальнейшие запросы. Состояние сохраняется и
  после перезагрузки обработка возобновляется, пока пользователь не остановит её
  или задание не будет завершено.
- «Обновить спрос» принудительно обновляет статистику видимых карточек.
- «Спрос карт» включает и выключает загрузку и отображение статистики. По
  умолчанию функция включена, а выбранное состояние сохраняется после
  перезагрузки. При выключении активный запрос может завершиться, но следующие
  карты из очереди уже не запрашиваются.
- «Скорость» переключает режимы по кругу: 1 → 3 → 5 запросов в секунду. Выбор
  сохраняется и применяется к следующему запросу без перезагрузки страницы.
  Фактическое время появления карточки также зависит от скорости ответа сайта:
  для полной статистики одной карты может понадобиться до трёх запросов.
- «Авто-лут» изначально выключен. После явного включения состояние сохраняется,
  расширение следит за уведомлениями о найденных картах, автоматически нажимает
  каждое из них и закрывает информационное окно. Запрос и время выдачи карты
  остаются под управлением самого сайта, поэтому после обработки уведомления
  встроенный таймер AnimeSSS может выдать следующую карту.
- «Авто-кристалл» изначально выключен. После включения расширение выполняет
  проверку сразу, а затем каждые 3 минуты. Сначала оно нажимает видимую кнопку
  «Я ВЕРНУЛСЯ», если сайт показал окно отсутствия. Затем нажимает кристалл только
  в том же сообщении, где точно написано: «Шпион демонической секты отобрал 300
  мешков с камнями духа, помогите их собрать». Каждый `data-code` обрабатывается
  не более одного раза, в том числе после перезагрузки страницы. Выключение
  функции останавливает периодическую проверку.
- «Авто-взнос клуба» изначально выключен. Функция предназначена для страницы
  `https://animesss.com/clubs/boost/?id=402`: вкладку нужно оставить открытой.
  С 21:00 до 22:30 МСК расширение последовательно нажимает «Обновить карту» и
  «Внести карту», делая паузы 300 и 800 мс. В 22:30 цикл прекращается до
  следующего дня; неиспользованный остаток не переносится. За одну московскую
  дату оно выполняет не
  более 20 собственных взносов. Общий прогресс, показанный сайтом за всё время,
  в дневной лимит не входит. В новую московскую дату счётчик расширения
  сбрасывается. Настройка и текущий дневной счётчик сохраняются после
  перезагрузки. Если открыть страницу между 21:00 и 22:30, незавершённый дневной
  запуск начинается сразу. После 22:30 новый запуск планируется на 21:00
  следующего дня. Чтобы исключить дублирующие клики, оставляйте открытой только
  одну вкладку этой страницы. Если общий прогресс сайта достигает максимума,
  например `600/600`, клуб считается закрытым: текущий цикл прекращается и новые
  запуски не планируются. После сброса общего прогресса сайтом достаточно
  перезагрузить страницу.
- «Массовый обмен» собирает только видимые незаблокированные карты. Перед первым
  запросом Chrome показывает подтверждение с количеством карт. Во время работы
  эта же кнопка останавливает запуск следующих запросов.
- «Очистить кэш» удаляет сохранённую статистику, не затрагивая данные сайта.

Для авто-лута, авто-взноса клуба, массового обмена и проверки задания необходимо
заранее войти в свой аккаунт Animesss в этой же вкладке.

При кратковременной сетевой ошибке запрос статистики повторяется до трёх раз.
Ошибка одной категории не останавливает отображение остальных показателей.

## Конфиденциальность

Расширение выполняет запросы только к текущему сайту Animesss, используя уже
открытую пользовательскую сессию. Оно не подключает аналитику и не отправляет
данные на сторонние домены.

В Chrome Storage сохраняются настройки включения, дневной счётчик клубных
взносов, статистика карточек со сроком жизни 24 часа, соответствия ID экземпляров
и последние 100 уже обработанных кодов кристаллов. Пароль, cookie и содержимое
сообщений расширение не сохраняет;
при включённом авто-кристалле оно локально сравнивает текст сообщений чата только
с указанной выше фразой события.

## Ручная проверка

1. На странице коллекции статистика появляется без запуска «Просветления».
2. Динамически загруженная карточка получает ровно один блок статистики.
3. Выключение «Спроса карт» скрывает статистику и останавливает очередь после
   текущего запроса; повторное включение загружает видимые карточки.
4. Кнопка скорости переключает 1, 3 и 5 запросов в секунду, а выбранный режим
   сохраняется после перезагрузки.
5. После перезагрузки настройки спроса и авто-лута сохраняют состояние.
6. После включения авто-кристалл нажимает «Я ВЕРНУЛСЯ», если кнопка видима,
   проверяет подходящий кристалл сразу и затем повторяет проверку каждые 3 минуты.
7. Отмена подтверждения массового обмена не создаёт запросов.
8. Подтверждённый обмен пропускает заблокированные карты, а кнопка остановки не
   запускает следующий запрос после завершения текущего.
9. Запуск, остановка и автопродолжение «Просветления» работают как раньше.
10. На странице клуба `id=402` авто-взнос работает только с 21:00 до 22:30 МСК,
    после перезагрузки продолжает с сохранённого количества и останавливается на
    20 картах, при завершении временного окна или при общем прогрессе `600/600`.
