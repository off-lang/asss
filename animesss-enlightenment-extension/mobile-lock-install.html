Карты A — блокировка и отмена

Для Chrome на телефоне. Только ваши карты A, без A+.

Третья кнопка: разблокировать только сделанное закладкой

Снимает замки только с карт A, ID которых записаны новой версией этой закладки после подтверждения блокировки. Предыдущие версии сохраняли лишь количество: старые блокировки нельзя восстановить по журналу, они не затрагиваются.

Учёт привязан к аккаунту, браузеру и домену сайта. Очистка данных сайта удаляет этот учёт. Если вручную снять и снова поставить замок на учтённой карте между запусками, закладка не сможет отличить этот новый ручной замок — не меняйте такие замки вручную до отмены через закладку. Спорные результаты запросов автоматически не разблокируются и не повторяются.

  1. Скопируйте весь код ниже.
  2. Замените адрес старой закладки на этот код. Название: «Блокировка A».
  3. Обновите страницу своей коллекции Animesss и запустите закладку через адресную строку Chrome.
  4. Выберите нужную кнопку и подтвердите запуск.

Вся коллекция — по страницам: страницы 1, 2, 3…; проверяется закрытый замок после каждой массовой блокировки.

Незаблокированные — первая страница: скрипт сам включает фильтр A и locked=0 в запросах, каждый раз читает страницу 1, пока список не опустеет. Счётчик основан на успешном ответе сайта и исчезновении отправленных карт из этой выборки. Если карты не исчезли или стали недоступны — остановка, без перехода вперёд.

Держите вкладку открытой и экран включённым. Не меняйте карты параллельно в другой вкладке. Есть «Стоп» и «Скопировать лог». Журнал последних 1000 строк хранится в этом браузере для текущего домена. При ошибке автоматического повтора нет.

Если кнопка копирования недоступна при открытии локального файла, скопируйте выделенный код вручную. Блокировка на вашем аккаунте во время разработки не запускалась.
